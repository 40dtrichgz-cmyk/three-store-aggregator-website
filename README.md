# 4zHouse.Site

Thai storefront aggregator for three shops: knockdown homes, kiosk counters, and pet houses. The app includes light and dark themes, responsive navigation, glass-style cards with 3D hover motion, product galleries, and each store's TikTok and Facebook links.

## Run locally

```sh
npm ci
npm run dev
```

## Validate

```sh
npm run typecheck
npm run lint
npm run build
```

The listed product names, descriptions, and prices are sample content. Update `src/data/stores.ts` with current store information before relying on them.
